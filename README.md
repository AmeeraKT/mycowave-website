# MycoWave

A prototype concept website made for the UQ Underground Brain project with two views for kids and mycologists.

## Pages
- `index.html': welcome screen, with option to choose the kids' or mycologist view.
- `kids.html`: the kids' landing page.
- `mycologist.html`: the mycologist observation viewer.

## Audio Credit
